# 公共图片固有尺寸（2026-07-13）

## 范围

为 16 个静态位图引用补充源图片真实的 `width` / `height` 元数据：

- 公共导航 Logo 1 处；
- 艺术家页静态活动图片 3 处；
- 关于我们页面合作伙伴图片 6 处；
- 三个特殊展览页各自开篇的两张图片，共 6 处。

尺寸均来自保留的旧 `Content` 参考树。数据库动态路径和 SVG 尺寸不由视图固定，因此保持不变，没有臆造统一比例。

## 响应式约束

这些 HTML 属性只描述资源的固有比例，不是把 CSS 显示尺寸改成像素。现有 `vh`、`vw`、百分比、`rem`、固定容器和 `object-fit` 仍然决定实际页面几何；浏览器只是能在图片下载完成前预留正确比例，减少布局偏移。

本轮未修改图片路径、CSS、加载优先级或视觉样式，也未访问服务器、发布目录或写入数据库。

静态断言确认 16 处均命中预期源尺寸；`dotnet build` 0 warning / 0 error，测试 110/110，`npm run build` 与 `git diff --check` 均通过。首页两档浏览器回归同时确认新增比例元数据未引入横向溢出；其余页面仅记录静态/构建验证，不声称完成本轮单独浏览器复测。

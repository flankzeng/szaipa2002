## 新增工具：`wechat-history-probe`
- 命令：`dotnet Szaipa.Web.dll wechat-history-probe [--scan-from yyyy-MM-dd] [--out 文件.json]`，与 `wechat-probe` 使用同一套配置（配置文件 + 后台加密保存的凭据），跑完即退出，不启动站点。
- 会逐个调用可能列出历史文章的接口：发布记录、草稿箱、永久图文素材、自定义菜单、自动回复、数据统计。每个接口报告「可用 / 错误码」，并汇总拿到的标题、链接和群发 msgid。如果「图文群发每日数据」可用且传了 `--scan-from`，会逐日扫描，得到群发标题清单。
- 只读保障：`WeChatApiClient.QueryReadOnlyAsync` 只放行一张查询类接口白名单 `ReadOnlyQueryPaths`，其他路径直接拒绝。发布、群发、删除类接口不在名单里，单元测试会检查这一点。输出不含 AppSecret 和 access_token。
- 代码：`WeChatHistoryProbe.cs`、`WeChatProbeCommand.cs`、`Program.cs`；测试 `WeChatHistoryProbeTests`。全量测试 716 项全部通过（Web 290、Data 426）。

官方文档的说法与实测一致：
- 发布能力（`freepublish/*`）和数据统计接口的适用范围都标注为「仅认证」，即「仅允许企业主体已认证账号调用，未认证或不支持认证的账号无法调用」。
- 永久素材接口对公众号开放，标为 ✔。
- 发布能力文档最后编辑于 2025-07-09；社区引用的官方说明称，2025 年 7 月起回收了未认证账号的发布能力接口权限。

结论：在**当前未认证**的状态下，官方接口能拿到的正式文章链接只有永久素材这 14 篇，已全部取到。草稿箱接口虽然可用，但存在三个问题：
1. 只给临时预览链接，不能作为正式链接导入。
2. 无法从接口判断某份草稿是否发出过。
3. 草稿可能包含从未公开的内容。

因此**草稿箱不用于导入**，只作参考。草稿标题和 2022 年后的旧手录新闻有部分重合，例如「展览人物档案 vol.1」「灵性咏叹」「同构 · 未来沙龙」「张岚芊讲座预告」。

### 仍可走的合规途径
1. **公众号完成微信认证**（主体为其他组织，需按微信要求提交资质并缴费）。认证后有望开通 `freepublish/batchget` 和数据统计接口，届时重跑 `wechat-history-probe --scan-from 2014-12-01` 即可验证。
   - 两点未经验证：`freepublish/batchget` 是否包含后台「群发」出去的文章，官方文档没有写明；数据统计接口只给标题和 msgid，不给链接。所以认证后能补到多少，要以实测为准。
2. **用户在公众号后台「内容管理 → 发表记录」复制链接**。那里会显示每篇的已删除、已隐藏状态，是目前唯一能完整排除已删除或隐藏文章的来源。
   - 复制完整链接，保留 `chksm`。
   - 每组不超过 50 条，在后台「公众号同步 → 批量链接导入」粘贴。

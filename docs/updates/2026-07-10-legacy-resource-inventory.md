# Legacy 资源审计（第一轮，2026-07-10）

本轮只做引用核对和分级，不删除旧资源。静态源码无法证明数据库动态路径、历史外链或后台上传是否仍在使用，因此“未发现静态引用”只能进入候选区，不能直接判定可删。

- `fonts`：保留原字库作字形兜底；前台优先加载同字体核心子集，不替换字体。

- Tongou 数据实体、后台管理和上传目录仍保留。公开 `Project_Tongou` 页面退役，不代表后台数据和文件可以删除。

## 字体结论

- 运行目录原 `SmilelySans.woff` 约 1.3MB；现代站核心子集约 168KB，并保留原字体同族兜底。
- 旧目录 Noto Sans SC 单字重通常约 5.1–6.3MB；当前 Light/Medium 核心子集各约 196KB。

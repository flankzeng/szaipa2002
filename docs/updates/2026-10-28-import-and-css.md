| 底栏链接显示 bootstrap 默认蓝 #337ab7 | 旧 `public-layout-main.css` 的 `.copyright-container a/p { color:#939393 }` 没有并入 `public-layout.css` | 补回颜色 |

- **定时同步一直报“未完成”**：素材接口里那篇纯视频文章每轮都被算作“失败 1”。新增状态 `Skipped`：页面正常但没有可展示正文的文章（纯视频、转载他号文章的分享卡片）记为“已跳过”，不算失败。来源状态、批量导入摘要和定时同步日志都增加了“跳过”计数，后台显示“已跳过”。
- **批量导入慢**：一批 50 条要 5–6 分钟，整段时间页面一直在转圈。单篇的正文图原来逐张串行下载，现在改为 4 张并发，并对图片地址去重。图片写入本来就用“临时文件 + 改名”，支持并发。

- 全量测试 717 项通过；新增测试：没有正文的文章返回 Skipped，不写新闻，也不下载图片。

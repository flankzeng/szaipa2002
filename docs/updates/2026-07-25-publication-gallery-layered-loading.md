# 2026-07-25 数据展览图库分层加载

## 范围

数据驱动展览的普通型 `_ExhibitionGallery` 与重要型 `_ExhibitionImportant` 过去虽然给图片
加了 native lazy loading，但主画廊和缩略条仍都输出原图 URL。对 70–131 图的大展览，
横向缩略条可能触发大量原图请求。

本轮复用既有只读 `ILegacyImagePreviewResolver` 和外置 Content 中已经存在的
`q30w1200`，没有生成、修改、复制或删除任何图片：

- 缩略条命中时永久使用预览；
- 主画廊命中时先显示预览，并保留 `data-original-src`；
- 图库进入视口前不主动恢复原图；
- 进入视口后只预载并恢复 active / previous / next；
- 每次切换只扩展到新的相邻范围；
- 预览缺失、歧义或路径非法时仍安全回原图。

## 命中与体积

14 个退役展览共 604 张精确路径，其中 344 张命中已有预览（约 56.95%）。这些命中图片的
原图合计 182,939,793B，对应预览合计 17,753,081B。作为缩略表示时减少
165,186,712B（90.30%）。

这组数字是 14 个页面全部命中资源的集合，不代表单次访问一定下载全部缩略图；浏览器仍会
结合 lazy loading 决定实际请求。它也不牺牲主图画质，因为用户当前看到及相邻的主图会
恢复原始 URL。

- 初始化后主画廊：3 张原图、128 张预览；
- 缩略条：131/131 使用预览；
- 点击下一张后：原图从 3 增至 4，未把其余图片批量恢复；
- 1440×900：2 个 Swiper 正常，无横向溢出、无图片失败；
- 390×844：`scrollWidth=clientWidth=390`，仍只恢复 3 张当前/相邻原图；
- 控制台无 warning/error。

代码契约继续由现有 Web 测试覆盖；完整基线保持 Data 98 + Web 147 = 245 项全绿，
.NET build 0 warning / 0 error。

本轮没有修改数据库、服务器、IIS、旧发布版、外置 Content 或 `szaipa2026`。

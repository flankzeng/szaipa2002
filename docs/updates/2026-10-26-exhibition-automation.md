# 展览自动化与专题积木（2026-10-26）

## 改动

- 展览后台按生命周期筛选并显示徽标；状态选项明确为「按日期自动 / 强制已结束 / 下架」。专题类型加入主题色、横幅和可排序积木编辑区。
- 新增首页推荐管理 CRUD，可配置卡片、图片、显示状态、轮播及顺序；首页原硬编码卡片保持缺表/未接管链接时的兼容行为。
- 首页推荐增加日期/状态归属：指向 `/Home/Publication/{id}` 的卡片先读正式数据库展览行，再使用兼容目录；slug / 自包含卡片使用后台日期字段。卡片按统一生命周期排序并展示状态，轮播保留编辑者勾选的历史展览。
- 添加 `FeaturedExhibition`、`PublicationBlock` 与 Publication 专题列的幂等 SQL，登记首页原有四个推荐展览；页面数据清洗仍由既有仓储执行。
- 漫MAN兼容目录及 slug 迁移 SQL 的结束日按用户确认修正为 2024-05-28。

## 原因与旧问题

过去展览状态主要由手动标志控制，新专题需修改大型 Razor 模板，首页推荐也不能由后台管理。现在日期状态和数据库推荐信息集中管理；`Status=false` 表示强制已结束，`null` 表示下架。推荐日期由链接对应的展览记录或兼容目录提供；春语III使用其专题日期字段。漫MAN 结束日期统一为用户确认的 2024-05-28，执行 slug SQL 后与未执行前生命周期相同。

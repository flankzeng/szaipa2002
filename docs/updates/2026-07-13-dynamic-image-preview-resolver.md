# 动态图片预览解析器（2026-07-13）

## 实现

现代 Web 新增 `ILegacyImagePreviewResolver`。它接收数据库或页面模型中的原始
`/Content/...` 图片 URL，并在 `LegacyAssets:ContentRoot` 下只读检查已有的
`_preview/q30w1200/Content/...` 预览文件：

- 命中时返回 `/Content/_preview/q30w1200/Content/...` URL；
- 首次使用时只读索引预览树，以忽略大小写的键查找、以磁盘真实大小写生成 URL；
- 当前审计的预览文件均为 JPEG，因此先尝试同名 `.jpg`，再保留未来同扩展预览的兼容候选；
- 仅为 JPG、JPEG、PNG 源图解析预览，GIF、WebP、SVG 和其他格式原样回退；
- 返回路径按 `/` 分段进行 UTF-8 URL 编码，安全支持空格、Unicode、撇号和多点文件名；
- 查询串和片段标识保持不变；
- 缺少配置、预览不存在或输入不适用时原样回退，不影响图片正常显示；
- 索引和命中/未命中结果均保存在进程内线程安全缓存，避免每次渲染都重复访问文件系统；
- 忽略大小写后若同一键对应多个文件，则该键视为歧义并回退原图。

解析器已经以单例注册到现代 Web 的依赖注入容器。

## 首批视图接入

第一批只接入适合直接使用 q30w1200 预览的小图和卡片图：

- 首页 `NewIndex` 的重要新闻封面；
- `NewNews` 列表的重要新闻封面；
- `NewVip` 的会员卡头像；
- `NewArt` 简介区头像；
- `PublicationList` 的展会卡片封面。

五处均把原 `/Content/...` URL 交给解析器。已有预览时只改变 `src`，预览缺失时
仍输出原 URL；原有 `loading`、`decoding`、HTML 结构和 CSS 展示规则保持不变。

以下图片有意不纳入首批：

- 首页 Hero、展览 Logo 和动态大画面活动轮播；
- 首页已结束展会的约定式 `card.jpg`；
- `NewArt` 的全屏 Banner、作品 Magnify 图片和 83vh 相关展览图片。

其中 Hero/Banner/大轮播属于大画面或 LCP，不能直接套用 q30；Magnify 作品需要先完成
按首次交互初始化，避免页面打开时预载原图；`card.jpg` 在参考树中没有可验证的预览覆盖。

## 安全边界

- 仅接受站内根路径 `/Content/...`，外部 URL、协议相对 URL与其他目录原样回退；
- URL 路径解码后逐段拒绝 `.`、`..`、空段、反斜线、控制字符和重复解析预览路径；
- 只从 q30w1200 预览根开始向下建立索引，不接受请求输入拼接出的任意物理路径；
- 索引遍历跳过文件或目录重解析点（符号链接等），目录枚举和权限异常安全回退；
- 解析器只读取目录项和文件属性，不打开文件内容，也不创建、修改或删除任何资源；
- 文件系统异常按未命中处理，响应中只会出现公开 URL，不会包含配置的物理路径。

纯文件单元测试使用临时目录覆盖 JPEG 命中、PNG 转 JPEG、扩展优先级、缺失与无配置回退、
非 Content URL、查询串、磁盘大小写保留、大小写歧义、空格/Unicode/撇号/多点文件名、
不支持扩展、编码分隔符、空白输入、遍历拦截及未命中缓存。

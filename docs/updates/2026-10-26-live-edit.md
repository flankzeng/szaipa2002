# 2026-10-26 现场编辑（T6）+ 会员风采排序（T7）

## 用户需求
后台像现代 H5 编辑器一样：打开「微缩版」官网，直接在页面上点文字修改；不只首页，新闻等帖子也能点进去现场编辑。另：会员风采要能排序。

## 现场编辑怎么用
1. 后台顶部导航「现场编辑」→ 打开微缩官网（手机/平板/电脑三种尺寸，可点常用页面或输入地址）。
2. 带红色虚线框的文字都能改：点一下 → 直接打字 → 回车（多行内容用 Ctrl/⌘+回车）或点别处即保存，Esc 取消。
3. 新闻正文这类富文本：点一下弹出编辑框（可插图、加粗、列表等），点「保存」。
4. 页面里的链接照常可点（例如从首页点进新闻详情继续编辑）；带虚线框的文字即使在链接里，点击也只进入编辑。
5. 保存立即生效并写入「操作记录」。退出：微缩页右上「退出现场编辑」或页面底部状态条「退出编辑」。

## 设计要点
- **在真实前台页面上叠加编辑层**，所见即所得。只有「已登录后台 + 进入现场编辑」时前台才输出编辑标记和脚本，编辑态页面不缓存；普通访客页面 HTML 与之前完全相同（已用匿名请求核对：0 个编辑标记）。
- 两类可编辑内容：
  - 数据库字段：白名单 `LiveEditRegistry`（新闻、艺术家资讯、艺术家、作品、展览、首页推荐、组织成员、在售作品、合作伙伴、出版著作的文字字段）。图片路径、排序、关联等字段不能通过现场编辑修改。
  - 模板里写死的文字：新表 `SiteText`，默认值仍是模板原文，没改过或表未建时显示原文。
- 安全：防伪令牌、后台权限策略、白名单、富文本清洗、长度/必填校验、操作记录。
- 视图用法（给后续开发）：`@LiveEdit.Text("key", "原文")`（写死文字）、`@LiveEdit.Field("实体", id, "字段", 值)`（数据库文字，非编辑态输出与 `@值` 完全一致）、`<div @LiveEdit.Attr("实体", id, "字段")>`（富文本容器）。

## 上线注意

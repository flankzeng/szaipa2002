# 会员风采（/Home/Vip）排序与显隐（T7）

## 改动

- **新表 `dbo.ArtistDisplay` / 实体 `ArtistDisplay`**：`ArtistId`（int，主键、非自增）、`Sort`（int，默认 0）、`IsHidden`（bit，默认 0）。**不改 `Artist` 表**；一位艺术家最多一行。表映射集中在 `ArtistDisplayModelConfiguration`（照 `ArtistBookModelConfiguration`），读上下文 `SzaipaLegacyReadContext` 与写上下文 `SzaipaAdminContext` 的 `OnModelCreating` 各追加一行共用，本地镜像 `mirror-sync` 会随 admin 模型自动出现空表。
- **前台规则**（`VipDisplayOrder`，前台与后台排序页共用，保证「后台看到的顺序 = 前台顺序」）：有记录的按 `Sort` 升序排在前面（同 Sort 保持 Id 倒序）；**没有记录的保持原 Id 倒序排在后面**；`IsHidden` 的不显示。`IArtistReadRepository` 新增 `GetVipArtistsAsync`，`HomeController.Vip` 改调它（一行改动）。`Vip.cshtml` 与卡片样式完全未动。
  - 隐藏只影响 Vip 列表；`/Home/Art/{id}` 艺术家官网页本身仍可访问（已实测 200）。
  - **缺表回退**：`ArtistDisplay` 不存在时（SQL Server 错误号 208，用 `SchemaCompatibility.IsMissingTable`，不依赖中文报错文字）完全回退 `GetArtistsAsync(newestFirst: true)` 的原顺序、无隐藏，绝不 500。
- **后台 `/Staff/VipOrder`**（`VipOrderController` + `Views/VipOrder/Index.cshtml` + `wwwroot/admin/vip-order.js`；仓储 `VipOrderAdminRepository`，`IVipOrderAdminRepository` 在 `SzaipaDataServiceCollectionExtensions` 追加注册）：
  - 列出全部艺术家（头像、中英文名、显示中/已隐藏），顺序同前台；**HTML5 拖拽排序，拖完即 POST 保存整份顺序**（写法照 `artist-site.js` 的作品排序：防伪令牌走 `RequestVerificationToken` 请求头、同一顺序不重复提交），另有「保存顺序」按钮兜底，以及 ▲▼ 按钮（触屏没有 HTML5 拖拽，键盘也可用）。
  - 显示/隐藏切换是普通 POST 表单（防伪）+ 跳回列表 + 提示。
  - 所有写操作 `[Authorize(Policy = AdminAuthorization.StaffPolicy)]` + `[ValidateAntiForgeryToken]` + `IOperationRecorder` 审计（Diary 与 Staff 同事务）。
  - 缺表时 `OnActionExecutionAsync` 捕获缺表/缺列，显示 `_SchemaMissing`「需先执行 SQL」；保存接口缺表返回 409 JSON 而不是 HTML。
  - 导航：`_StaffLayout.cshtml`「首页 / 关于我们」分组在「组织架构」下方追加「会员风采排序」，`VipOrder` 加入 `contentControllers`。
- **写入策略**：每次保存/隐藏都把「当前前台顺序」固化成每位艺术家一行（`Sort=1..n`），之后新增的会员（没有记录）统一排在最后，已有顺序不会因局部改动漂移；对没有记录的会员点「显示」不产生任何写入；请求里不存在/重复的 Id 被忽略，没提到的保持现有相对顺序接在后面。
- **SQL**：`docs/sql/2026-10-26-vip-order.sql`（幂等 `IF OBJECT_ID(...) IS NULL CREATE TABLE`）；已加入 `scripts/build-automation-sql.py` 来源清单末位并重新生成 `2026-10-26-automation-deploy.sql`（`--check` 提示「八份来源一致」）；`2026-10-26-automation-rollback.sql` 的盘点表清单与拆除逻辑追加 `ArtistDisplay`（默认只读盘点，有数据拒绝拆除）。
- Tailwind：新视图用了新类（`data-[hidden=true]:opacity-60` 等），已重新生成 `wwwroot/admin/admin.css`。

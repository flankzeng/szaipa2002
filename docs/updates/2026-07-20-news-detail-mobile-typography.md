# 新闻详情页手机排版修复（2026-07-20）

## 根因

`/Home/NewNewsRead/{id}` 仍会加载旧版 `responsive.css`。该文件在窄屏下有两条
全局强制规则：

- `html` 根字号被放大到 26px，所有 `rem` 文字一起被放大；
- `.article p` 行高被改为 `5em !important`，段落出现过大空档和内容遮挡。

新闻详情页原有的两个栅格占位还会在手机上保留 `float`，把 90% 宽的正文挤到
一侧。面包屑和右上日期因此叠在一起。

## 修复

- 只在新闻详情页的手机媒体查询内，用百分比 + `vw` 的 `clamp()` 恢复稳定根字号；
- 给富文本增加 `.article-body` 作用域，仅在手机端归一化段落、内联文字和标题的
  `rem` 字号与无单位行高，覆盖旧版 `!important` 而不改写文章数据；
- 图片保持原比例，以 `max-width: 100%` 约束在正文宽度内；
- 手机端隐藏文章两侧的 legacy 栅格占位，正文清除浮动并占满 100% 宽度；
- 面包屑改为允许安全折行的 flex 布局，日期独立在右上；
- navbar 仍保持四项单行横排和 `nowrap`。

## 真实页面验证

以只读数据库和参考 Content 启动本地站点，实际打开
`/Home/NewNewsRead/1124`：

- 390×844：根字号 15.99px，正文 15.99px / 1.75 行高，标题 24.96px；
- 320×568：根字号 15px，正文 15px / 1.75 行高，标题 21.75px；
- 修复范围与 legacy 规则一致延伸到 991 宽，另在 768 和 991 两个平板边界复测；
- 四个视口均为 `scrollWidth == clientWidth`，无横向溢出；
- navbar 四项在同一行、横排、不换行，全部位于视口内；
- 面包屑六个元素均可见且不与日期重叠；
- 实际滚动检查正文段落、作品图和富文本标题，字号与行高正常。

本批只修改现代站源码，没有写数据库、没有更改外置 Content，也没有触碰
Windows 服务器或稳定发布版。

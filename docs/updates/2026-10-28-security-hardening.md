# 2026-10-28 应用层安全加固：扫描拦截、登录防爆破、安全响应头

## 背景
近 30 天正式站日志中约 1.36 万次请求是漏洞扫描（探测本站不存在的 .php、wp-、.env、.git 等路径）。后台监控已由 Codex 完成（`558ec41`），本次只做防护。

## 改动
- `SecurityShieldMiddleware`（管道最前）：
  - 所有响应加 `X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`（现场编辑用同源 iframe）、`Referrer-Policy: strict-origin-when-cross-origin`、`Permissions-Policy`。
  - 探测路径直接 404，不进入静态文件 / 路由 / MVC；同一 IP 10 分钟内 ≥10 次探测封禁 24 小时（期间所有请求 403）。本机、内网与服务器白名单中的 IP 永不封禁；不拦 `/.well-known/`（证书续期）。
- `LoginThrottle`：后台登录同一 IP 10 分钟输错 5 次、或同一账户输错 10 次，锁定 15 分钟；锁定期不查库；登录成功清零。
- 状态在进程内存中，应用池重启后清空。

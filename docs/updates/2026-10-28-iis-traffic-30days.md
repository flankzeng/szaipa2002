## 数据范围与说明
- 来源：正式站 IIS W3C 日志 `C:\inetpub\logs\LogFiles\W3SVC1`，**2026-09-28 至 2026-10-28**（31 个文件）。更早的日志已在当天磁盘清理中删除，本轮未核实云控制台快照，不能断言所有恢复途径均不存在（见 `2026-10-28-mobile-legacy-scale-and-live-edit.md` 第 15 节）。
- 旧站自带埋点 `requests-*.log` 当时在服务器上未找到现存文件（`C:\Security\audit` 自 8 月起为空），本报告使用IIS逐请求数据；数据库AccessData/Diary另有历史埋点。
- 统计在服务器上只读完成，只取汇总数，逐条记录（IP、UA）未离开服务器、未进 Git。剔除：本 agent 测试流量（本机出口、服务器本机、白名单 IP，共 1,370 次）、静态资源、`/healthz`、后台 `/Staff`。
- 切换时间：2026-10-27 20:06:58（北京时间），之前为旧 MVC 站，之后为新站。
- 局限：仅凭 UA 和行为推断，**不等于真人点击**；浏览器缓存了 CSS/JS 的回访者可能被少算。

## 主要结论
| 指标 | 数值 |
|---|---|
| 总请求 | 231,840 |
| 漏洞扫描类请求（.php / wp- / .env / .git 等） | 13,579 |
| 声明为爬虫的页面请求 | 约 9,800（百度 1,982、字节 1,471、华为 Petal 636、Ahrefs 544、Google 539、Semrush 488、GPTBot 355 …） |
| 自称浏览器的页面访问 | 52,326 次，23,509 个 IP |
| 观察到CSS/JS请求的候选IP及对应页面请求（不证明真人） | **2,023 个 IP，9,756 次页面访问** |
| 每日候选IP（原启发式口径，不是人数） | **约 50–137，平均约 85 个IP/天** |

- **浏览器UA流量证据不足以判定真人比例**：2.35 万个 IP 中约2千个伴随样式和脚本请求（缓存会漏计，自动化也会请求资源）；首页 `/` 被访问 2.7 万次、九成以上无来源页。
- **来源**：缺失Referer不能推断直接访问；记录到的搜索来源较少（百度约 151、Google 约 68、Bing 9）。UA含微信特征约35次，不等于全部微信来源。
- **设备**：自称浏览器的访问中手机约 10%（仅为UA声明，不能推断真人设备比例）。
- **热门内容**（自称浏览器口径）：首页、新闻列表、会员风采；艺术家页 1027（栗子）、1009（姚建伟）、1029（王绍强）、1012（王玉波）、1031（赵能智）等各约 300–400 次；旧新闻详情若干篇各 200–300 次。
- **错误**：404 共 23,744（主要是扫描）；500 共 4,169，集中在旧站 `/home/newart/1048`、`/home/news/`、`/home/newlink`、`/home/works/*`。新站上这些地址已经 301 跳转到新地址或返回 404，不再报 500。
- **切换后（10-27 20:06 起约 1 天）**：自称浏览器页面访问 669 次 / 470 个 IP。新站上线时间太短，暂不足以和旧站比较。

## 建议
1. 若要增加真人判定证据，可启用专门的访问统计（仍不能保证识别所有真人）：新站自带请求审计（`SecurityMonitoring:RequestAuditEnabled`，此报告原统计时关闭，当前以实际部署配置为准），或接入第三方统计。开启前需确认磁盘空间与保留天数。
2. IIS 日志按天增长约 2 MB，近 31 天日志保留，不再删除；以后的清理应排除 `C:\inetpub\logs`。
3. 搜索流量很低，可考虑提交站点地图、完善页面标题与描述（SEO）。

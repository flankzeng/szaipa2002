# 2026-10-28 新闻“重要”（展示封面）恢复

## 用户需求

旧站新闻有「重要」标记：标为重要的新闻在新闻列表和首页显示**封面大卡片**（标题、简介、封面图、查看全部），其余只显示日期+标题。用户要求：

1. 恢复这个功能；
2. 公众号文章按群发规则自动标注——**每次群发的第一篇是重要**（单篇群发就是那一篇，两篇、三篇群发都是头条）；
3. 把已有文章批量标注一遍；
4. 后台能手动勾选哪些展示封面、哪些不展示。

## 原因

前台版式（`Views/Home/News.cshtml`、首页 `Index.cshtml` 第 6 屏）和数据字段 `News.Important` 一直都在，后台编辑页也有勾选框；但公众号同步写死 `Important = WeChatOptions.NewArticlesImportant`（默认 false）。所以 130 篇同步新闻全是 false，新闻列表和首页一张封面都不显示。

## 改动（`bf66b11`→ 修订为 `dc7b14d`，`ccba735`）

| 位置 | 改动 |
|---|---|
| 同步 `WeChatSyncService` | 新建新闻时 `Important = NewArticlesImportant \|\| (ItemIndex == 0 且有封面)`。`ItemIndex` 来自文章页 `idx-1` 或接口 `news_item` 下标。没有封面的头条不标（否则前台是破图）。只在新建时决定，更新/重新抓取不改，后台手动取消的不会被同步冲回来。 |
| 批量补标 `WeChatSyncAdminRepository.MarkLeadArticlesImportantAsync` | 按 `SourceKey` 归并同一次群发（`mp:{biz}:{mid}:{idx}` → `mp:{biz}:{mid}`），取未隐藏、新闻存在且有封面、序号最小的一篇设为重要。**只把 false/null 改成 true，不取消任何勾选**；头条被隐藏时由同次群发下一篇顶上；幂等；写 EditRecord 与操作记录。 |
| 公众号同步页 | 同步记录表头新增「按群发头条补标封面」按钮（有确认框）；原“置顶/取消置顶”改称“展示封面/取消封面”（实际一直是 Important，不是排序置顶）。 |
| 新闻管理列表 | 新增封面缩略图（480 宽 WebP 变体）+「展示封面」勾选框，勾选即保存，不用进编辑页；无封面的新闻显示“无封面”不可勾。新接口 `POST /Staff/News/Important/{id}`。窄屏表格可左右滑动，日期/勾选/操作列不折行。 |
| 编辑页 | 勾选框文案改为“展示封面（重要新闻：新闻列表与首页显示封面大图，不勾则只显示日期和标题）”。 |

测试：新增次条为普通行、无封面头条不标、手动取消不被同步覆盖、`SetImportantAsync`、批量补标（隐藏头条顺延 / 无封面跳过 / 已有勾选保留 / 幂等）、群发分组键；全量 **723 项通过**。

# 公众号同步 · 操作指引（给运营/管理员）

> 目的：把「深圳市艺术产业促进会」(SZAIPA) 公众号已群发的文章同步到官网「新闻动态」，按现有新闻版式显示。
> 技术细节和上线顺序见 [automation-rollout.md](automation-rollout.md)；本页只讲你需要在公众号后台和电脑上做什么。

## 一、两种同步方式，先用哪个？

| 方式 | 需要什么 | 能同步什么 | 建议 |
|---|---|---|---|
| **粘贴链接导入**（主力） | 什么都不需要 | 任何一篇已发出的文章 | 补历史文章、日常兜底都用它 |
| **官方接口自动同步** | AppID + AppSecret + IP 白名单 | 只能拿到接口有权限的那部分（未认证号很可能没有权限） | 在后台「接口配置」页填好后先点「测试连接」，再决定开不开 |

公众号目前未认证。微信「发布」记录和「群发」历史不是同一份数据，所以**群发历史一定要靠粘贴链接导入补齐**，接口只是锦上添花。

## 二、粘贴链接导入（现在就能用）

1. 拿到文章链接，任选一种：
   - 电脑版微信：打开公众号 → 历史消息 → 打开文章 → 右上角「…」→「复制链接」；
   - 公众号后台 mp.weixin.qq.com →「内容管理 / 发表记录」→ 打开文章 → 复制浏览器地址栏。
   - **复制完整链接**（长链接里的 `chksm=…` 不能删，删了微信会弹人机验证导致导入失败）。
2. 登录官网后台 →「内容管理 → 新闻 → 公众号同步」。
3. 在「批量链接导入」里每行粘贴一条，一次最多 50 条，点「导入」。同一篇不管粘几次、长链接短链接，只会生成一条新闻。
4. 导入后的新闻可以在「新闻」模块里继续修改；不想在官网显示的，在同步记录里点「隐藏」；每次群发的头条会自动「展示封面」（前台带封面大图），其余为日期+标题行，可在同步记录或「新闻」列表里逐篇勾选/取消。
5. 如果某条提示「微信要求人机验证」，隔一会儿再试（短时间内请求太多会被微信限流），不要反复狂点。

## 三、配置官方接口（有空时做，不急）

### 1. 在公众号后台找到 AppID 和 AppSecret
mp.weixin.qq.com →「设置与开发 → 基本配置」（新版可能叫「开发接口管理」）：
- **开发者ID（AppID）**：直接可见，复制即可。
- **开发者密码（AppSecret）**：只在生成/重置时显示一次。
  - 如果当初生成时已经保存过，直接用保存的那份。
  - ⚠️ **找不到再点「重置」**：重置后旧密码立即作废，如果还有别的系统（第三方编辑器、小程序后台等）在用旧密码，它们会断。重置前先确认没有其他地方在用。

### 2. 配置 IP 白名单
同一页面「IP白名单」→ 添加**调用接口那台机器的公网出口 IP**（不是域名、不是内网地址）：
- 正式环境：官网服务器的公网出口 IP（部署后由服务器发起调用）。
- 不确定是哪个 IP：先做第 3 步保存，再点「测试连接」。没加白名单时微信返回 40164 并报出调用方 IP，后台页面会醒目提示「请把 x.x.x.x 加入公众号 IP 白名单」。
  （注意：微信先校验 AppID，AppID 不对时只会报 40013，看不到 IP。）
- 想先在这台 Mac 上测试：再临时加上 Mac 当前的公网 IP（在浏览器搜索「我的IP」即可看到），测完可以删掉。

### 3. 在后台设置页填写（推荐）
登录官网后台 →「内容管理 → 公众号接口配置」（或「公众号同步」页顶部的「接口配置」选项卡），地址 `/Staff/WeChat/Settings`：
1. 填 AppID 和 AppSecret，**先不要勾**「启用自动同步」，点「加密保存」。
   - AppSecret 只写：保存后加密存放在服务器上，页面只显示「已设置，末 4 位 ****xxxx」；留空表示不修改，要撤掉用「清除已保存的 AppSecret」。
   - 保存立即生效，不用重启网站。
2. 点「测试连接」逐项看结果：token 可用 = 凭据和白名单都对；40013/40125 = AppID 或 AppSecret 不对；40164 = 白名单（页面给出要加的 IP）；48001/50001 = 该接口没有权限（未认证号常见）。
3. 把「不可用」的来源取消勾选；至少一个来源可用时勾选「启用自动同步」再保存，后台按「同步间隔」自动检查新文章（无需重启）。都不可用就别开，继续用链接导入。

不要把 AppSecret 发到聊天、写进代码或文档。

### 3b. 备选：配置文件 / user-secrets / 环境变量
后台页面没保存的项沿用这里的配置；页面保存的值优先。
- **Mac 本地测试**：在终端执行（把中文换成真实值）：
  ```bash
  cd /Users/arthur/Project/GitClone/szaipa2002/src/Szaipa.Web && ~/.dotnet/dotnet user-secrets set "WeChat:AppId" "你的AppID"
  ```
  ```bash
  cd /Users/arthur/Project/GitClone/szaipa2002/src/Szaipa.Web && ~/.dotnet/dotnet user-secrets set "WeChat:AppSecret" "你的AppSecret"
  ```
- **服务器**：写在服务器上的 `appsettings.Production.json` 或环境变量 `WeChat__AppId`、`WeChat__AppSecret`（见上线手册），不要放进发布包或 Git。

### 4. 命令行能力探测（可选，开发同事用）
```bash
cd /Users/arthur/Project/GitClone/szaipa2002 && ~/.dotnet/dotnet run --project src/Szaipa.Web -- wechat-probe
```
结果与后台「测试连接」相同（同样叠加后台保存的配置），逐项显示 token、「发布记录接口」「永久图文素材接口」是否有权限、能拿到多少条，不打印密钥。
想核查「还有哪些接口能列出历史文章」：在服务器上运行 `dotnet Szaipa.Web.dll wechat-history-probe --out 清单.json`（Production 环境）。它逐项测试发布记录、草稿箱、永久素材、菜单、自动回复和数据统计接口，只调用查询类接口；认证后加 `--scan-from 2014-12-01` 可以逐日扫描群发标题。2026-10-28 的实测结果见 [updates/2026-10-28-wechat-history-api.md](updates/2026-10-28-wechat-history-api.md)。
只用配置文件时：没权限的来源关掉（`WeChat__Sources__FreePublish=false` / `WeChat__Sources__Material=false`），至少一个可用时设 `WeChat__Enabled=true`。

### 5. 服务器首次启用后台设置页（运维一次性）
正式环境必须配置存储位置，否则设置页显示「未配置存储位置」且不能保存（站点其他功能照常）：
- 配置 `WeChat:CredentialStorePath`（或环境变量 `WeChat__CredentialStorePath`）为发布目录之外的绝对路径，例如 `C:\SzaipaData\secure\wechat-credentials.json`；
- 给 IIS 应用池账号（如 `IIS AppPool\SzaipaNew`）该目录的**修改**权限；
- `DataProtection:KeysPath` 密钥目录不能丢：丢了已保存的 AppSecret 无法解密，页面会提示重新录入。

详见 [updates/2026-10-27-wechat-settings.md](updates/2026-10-27-wechat-settings.md)。

## 四、上线那天要做的一件事：隐藏旧的手录新闻
等历史文章用链接导入补齐后，把当时旧新闻的最大编号填进后台「接口配置」页的「旧新闻分界 Id」并保存（即时生效；也可用配置 `WeChat__LegacyNewsMaxId`；开发同事会告诉你数值）。
效果：旧手录新闻从列表和首页隐藏，**但旧链接仍能打开**（搜索引擎和外部引用不会断），数据不删除。

## 五、「群发完成自动推送」要不要开？（默认关闭）
可以让微信在每次群发后主动通知官网，但需要在公众号后台启用「服务器配置」。**一旦启用，公众号后台编辑模式下的自动回复和自定义菜单会失效**。如果你们在用自动回复/菜单，就别开，靠链接导入 + 定时接口即可。
